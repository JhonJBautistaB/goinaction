#  Aprendizaje de Go con "Go in Action" 

![Portada del libro Go in Action](https://drek4537l1klr.cloudfront.net/kennedy2/Figures/cover.jpg)

Este repositorio está dedicado al estudio y práctica del lenguaje Go, siguiendo el libro [**"Go in Action"**](https://livebook.manning.com/book/go-in-action-second-edition/welcome/v-7). El objetivo es aprender los conceptos fundamentales y avanzados de Go en un periodo de 4 semanas.

## Plan de estudio

- **Capitulo 1:** Introducing Go
- **Capitulo 2:** Diving into Go
- **Capitulo 3:** Primitive Types And Operators.
- **Capitulo 4:** Collection Types.
- **Capitulo 5:** Working With Types
- **Capitulo 6:** Generics
- **Capitulo 7:** Errors in Go
- **Capitulo 8:** Testing and Tooling

## Estructura

Organizar por carpeta de acuerdo a tema estudiado y el cual se realizó un proceso de prácticas.

## Requisitos

- Go instalado en el sistema ([descargar aquí](https://golang.org/dl/))
- Editor de código recomendado: VS Code o GoLand

## Recursos adicionales

- [Documentación oficial de Go](https://golang.org/doc/)
- [Go by Example](https://gobyexample.com/)
- [Go In Action Github Repository](https://github.com/flowchartsman/go-in-action)
